# Pong

Dieses Projekt ist ein Schulprojekt für die Softwareentwicklung (SEW) und wurde im Rahmen einer Gruppenarbeit entwickelt.

Es handelt sich um ein Abschlussprojekt aus dem Unterricht, das wir mit JavaFX umgesetzt haben. Das Spiel ist eine klassische Pong-Variante mit einfachen Menü- und Spielbildschirmen, unterschiedlicher Schwierigkeit und einer eigenen Spielstruktur.

## Beschreibung

Das Ziel des Projekts war es, ein einfaches, aber funktionales Spiel mit objektorientierter Programmierung und grafischer Benutzeroberfläche zu entwickeln. Dabei wurden grundlegende Konzepte der Spieleprogrammierung, der GUI-Programmierung mit JavaFX und der strukturierten Projektentwicklung angewendet.

## Ausführen

```bash
./mvnw clean javafx:run
```
